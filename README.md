Online Shop – Java Collection Framework
Project Description
This project demonstrates an Online Shop application developed using Java and the Java Collection Framework (JCF).
The project manages products, users, shopping carts, reviews, and orders using different collection types.
Technologies Used
• Java
• Object-Oriented Programming (OOP)
• Java Collection Framework (JCF)
• IntelliJ IDEA
Project Structure
• model – Contains domain classes such as Product, Clothing, Electronics, User, Order, and ShoppingCart.
• service – Contains ProductService, UserService, and OrderService.
• comparator – Contains custom comparators for sorting products.
JCF Features
• List (ArrayList) – Stores products.
• Set (HashSet) – Stores unique products and users.
• Map (HashMap) – Stores and searches objects by ID.
• Queue (ArrayDeque) – Processes orders using FIFO (First In, First Out).
• Comparable – Sorts products by ID.
• Comparator – Sorts products by name, price, and category.
Main Features
• Product management
• User management
• Shopping cart
• Product reviews
• Order management
• FIFO order processing
• Product searching and filtering
• Product analytics
How to Run
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java is configured.
4. Run Main.java.
